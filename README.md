## 💡 About

This course blends the programming language **Python** and the database management system **SQL** to help you analyze, visualize, and interpret data efficiently. It combines practical and theoretical knowledge through hands-on projects and real-world examples, making it a strong starting point for aspiring data scientists.

---

## ✍️ What You'll Learn

| | Skill |
|---|---|
| 🗂 | Data manipulation and cleaning using Python libraries such as NumPy and pandas. |
| 📈 | Statistical analysis and implementation of machine learning algorithms with Scikit-learn. |
| 📊 | Data visualization using Python libraries like Matplotlib. |
| 🗄 | SQL fundamentals, including querying, data extraction, and database management. |
| 🧱 | Effective handling of structured data using SQL. |
| 🧪 | Practical application of data science techniques through hands-on projects and real-world examples. |

## 🚀 How to Run

1. **Clone** the repository.
2. **Install** Jupyter and the packages used in the course:

   ```bash
   pip install jupyter numpy pandas matplotlib scikit-learn
   ```

3. **Launch** Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

4. **Open** the notebooks in the `Module 1 Introduction/` folder and run the cells.
